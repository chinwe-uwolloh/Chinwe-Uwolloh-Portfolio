## 🎖️ How to Earn GitHub Achievement Badges

GitHub automatically awards achievement badges to your profile based on your activity. Here's how to unlock each one:

| Badge | How to Earn |
|---|---|
| ⚡ **Quickdraw** | Close an issue or pull request within 5 minutes of opening it |
| 🦈 **Pull Shark** | Get 2+ pull requests merged (×2 for 16 merged, ×3 for 128 merged) |
| 🌌 **Galaxy Brain** | Have an answer accepted as the correct solution in GitHub Discussions |
| ⭐ **Starstruck** | Have a repository receive 16+ stars (×2 for 128, ×3 for 512, ×4 for 4096) |
| 👥 **Pair Extraordinaire** | Co-author a pull request that gets merged |
| 🎯 **YOLO** | Merge a pull request without a review |
| 🧊 **Arctic Code Vault Contributor** | Contribute code to a repository archived in the 2020 GitHub Arctic Code Vault |
| ❤️ **Public Sponsor** | Sponsor an open-source developer or project through GitHub Sponsors |

**Pro tips to grow your GitHub profile fast:**
1. **Commit daily** — maintain your contribution streak to build a green contribution graph
2. **Open source contributions** — contribute to popular repos to increase stars and PRs merged
3. **Pin your best repositories** — curate up to 6 pinned repos on your profile with compelling descriptions
4. **Write great READMEs** — projects with detailed READMEs get more stars
5. **Engage in Discussions** — answer questions in popular repos to earn Galaxy Brain
6. **Create repositories for each project** — gives your profile depth and demonstrates consistent output

## 🛠️ This Repository

This repo contains the source code for my personal portfolio website, built at principal-engineer level with a focus on performance, animation, and design systems.

### Tech Stack
| Layer | Technology |
|---|---|
| **Framework** | React 18 + Vite 5 |
| **Language** | TypeScript 5 |
| **Styling** | Tailwind CSS + shadcn/ui |
| **Animation** | Framer Motion + GSAP + Three.js |
| **Backend** | Supabase (PostgreSQL + Auth + Realtime) |
| **Deploy** | Custom domain via CNAME |

### Architecture Highlights
- **Component-driven design system** using Radix UI primitives with custom Tailwind themes
- **3D interactive elements** via React Three Fiber for immersive project showcases
- **Performance-first**: lazy loading, code splitting, and optimized asset pipelines
- **Responsive** across all breakpoints with fluid typography and spacing

### Run Locally

```bash
# Clone
git clone https://github.com/chinwe-uwolloh/Chinwe_U_Tech_Portfolio.git
cd Chinwe_U_Tech_Portfolio

# Install
npm install

# Develop
npm run dev

# Build for production
npm run build
```
